# 扫雷竞速：独立棋盘、逻辑可解、持久化存档

## 在线试玩

**https://minesweeper-arena-34333.app.workbuddy.host/**

无需注册登录，浏览器（手机/电脑）打开即可游玩，多人在线实时对战。

## 本地运行
需要 Node.js 18 或更高版本。在项目目录执行：

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。修改端口：`PORT=8080 npm start`（Windows PowerShell：`$env:PORT=8080; npm start`）。

## 已实现
- 简单 9×9/10 雷、中等 16×16/40 雷、困难 16×30/99 雷。
- 每位玩家独立棋盘、独立计时，排行榜跨玩家比较成绩。
- 服务端随机生成棋盘，并用保守的无猜测求解器验证；无法推理完成的棋盘会被拒绝并重新生成。
- 点哪开哪：棋盘在首次点击后围绕该点生成，首点及其周围一圈必定安全。
- 暂停/继续、保存并退出、退出不保存。
- `data/database.json` 持久化存档，服务器重启后仍可恢复。
- 每个浏览器玩家 ID、每种难度只保留一个最佳成绩。
- 500 MiB JSON 数据库硬上限；先清理历史，再清理较旧存档，最后才清理最佳成绩。存档 30 天过期，每位玩家每种难度最多保留 30 条历史记录。
- 断线时尝试自动保存正在进行的游戏。

## 关键说明
1. **可解性范围**：求解器使用零格展开、单格约束和子集推理，不猜测。它不是完整的人类推理证明器，可能拒绝某些实际上可解的棋盘；每次最多尝试 12000 个布局，极端情况下会提示重试。高难度生成耗时可能明显增加。
2. **首次点击**：你点击的格子及其周围一圈必定无雷。棋盘不在开局时预生成，而是在你首次点击后围绕该点即时生成并验证可解——所以点哪开哪，开局零等待。极少数情况下该起点排不出可解棋盘，页面会提示换一个格子点击。
3. **玩家身份**：玩家 ID 由服务器签发 HMAC 签名的 HttpOnly Cookie 管理，伪造身份会被拒绝；清除浏览器数据后重新访问会自动恢复/重签，无法通过自报 ID 刷榜。
4. **并发限制**：JSON 文件采用原子替换，但不是高并发数据库；多人同时大量写入时建议迁移到 SQLite/PostgreSQL。500 MiB 限制只针对 `data/database.json`，不包含系统日志或其他目录。
5. **安全加固**：已内置签名 Cookie 身份、HTTP 速率限制（60 次/分/IP）、Socket Origin 校验、事件级限流与畸形数据包防崩溃；公网 HTTPS 由托管平台反向代理提供。
6. **竞赛方式**：玩家各自创建独立棋盘并独立计时，排行榜比较最佳成绩；当前没有实时观看其他玩家棋盘的功能。
